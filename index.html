Record into MPC

The MPC starts recording as soon as you press its buttons, so this page waits for it. When the MPC starts, the page plays the loop once, in time with the MPC's clock, while the MPC records it into one of its sequences.

  1. Press SHIFT + PAD 8 for MIDI Configuration. Check MIDI Port is USB, MIDI In Channel is All and Pad MIDI In is On. Set MIDI Sync Out to MIDI Clock, so the MPC tells this page when it starts and how fast it's going, and set MIDI Sync In to Off.
  2. Choose an empty sequence on the MPC, and set its length to the same number of bars, the same as here. The MPC adds to what's already in a sequence, so an empty one keeps the notes from doubling up. The MPC's own tempo is used.
  3. If the MPC counts in before recording, turn its count-in off, so the loop lines up with the start of the sequence.
  4. If the MPC's timing correct (quantise) is on, turn it off, or set it at least as fine as the repeats here. Otherwise it pulls the hits of a repeat onto the same step, and they're lost.
  5. Click Wait for MPC below.
  6. On the MPC, press REC, then PLAY. The page plays the loop once as the MPC records, then stops sending.
  7. When the status says it's done, press STOP on the MPC. Play the sequence back to check it, and save the project on the MPC to keep it.

This hasn't been confirmed on an MPC Sample yet. If nothing happens when the MPC starts, check that MIDI Sync Out is on MIDI Clock, and that the MPC isn't in SD Card Access mode. Click Stop waiting to give up.

MPC Grid help

A step grid for the Akai MPC Sample. It plays the MPC live over USB and saves patterns into new copies of your projects, or back into the same project on the card if you choose. It doesn't change the MPC's firmware, and your files aren't uploaded anywhere. It needs a current Chrome or Edge on a computer.

Visits to this page are counted anonymously with GoatCounter, which uses no cookies. It never receives your projects, samples or patterns.

Set up your MPC Sample

  1. Connect the MPC to your computer with a USB-C data cable.
  2. On the MPC, press SHIFT + PAD 8 to open MIDI Configuration, then set MIDI Port to USB, MIDI In Channel to All and Pad MIDI In to On.
  3. Load a project that has samples on its pads. Empty pads make no sound, even when MIDI is working.
  4. In this page, allow MIDI access when asked. The MIDI badge turns green when the MPC is found.
  5. Click a pad name in the grid. You should hear that pad on the MPC.

MIDI mode and SD mode

The MPC can't do both at once:

  • MIDI mode (normal use): the grid can play the MPC, but it can't reach the card.
  • SD mode (SD Card Access in the MPC's Project menu, SHIFT + PAD 16): the grid can reach the card, but it can't play the MPC.

Once a project is open, it's kept in your library, so you can edit and play it in MIDI mode. You only need SD mode to move projects.

Your library folder

Click Choose library folder and pick or make a folder on this computer, such as Documents/MPC Library. Projects you open from the card, the new projects you save, and backups (in a backups folder) are kept there as normal MPC project files, so you can see them, back them up and copy them. Projects already kept in this browser are copied into it. Until you choose a folder, the library is kept privately in this browser.

On later visits the browser may ask again: click Allow library access. Each computer has its own library folder. Choose a folder on the computer, not the card.

Before leaving SD mode: eject the card on your computer, then press B1 on the MPC.

Open a project from the MPC

  1. On the MPC, save the project to the card. The grid can't see the MPC's internal storage.
  2. Enter SD mode.
  3. Click Connect card and choose your card. If the browser refuses it, choose the MPC-Sample/Projects folder on the card. You may need to allow access again on later visits.
  4. Choose the project under On the card in the Project menu.
  5. Eject the card and return to MIDI mode.

Save patterns to the MPC

The open project's name is shown large at the top.

  • Save (Cmd+S) puts your changes into the same project, under the same name. With the card connected in SD mode and the project on it, that's the project on the card, and your library's copy is updated too. Otherwise it's your library's copy, and the next Save with the card connected puts it on the card. If the project was also changed on the MPC in between, the page won't overwrite it, and says so. The previous version is always kept as a backup in your library, and samples aren't touched.
  • Save as… (Cmd+Shift+S) asks for a name and makes a new project in your library, leaving the original alone. Enter SD mode and click Copy to card to put it on the card.
  • Copy to card, at the bottom, writes the project as it is in the editor, unsaved changes included, to the card under its own name. If the card already has a project of that name, it's replaced, and the card's version is kept as a backup in your library first. Samples are copied too, and any already on the card are kept.
  • An MPC project is a file with a folder of samples beside it, so it's saved into your library rather than with the Mac's Save dialog, which saves single files.
  • Then eject the card, press B1, and load the project on the MPC. Sequence slots 1-16 match pads 1-16 in the MPC's Sequence Mode.

Unsaved patterns are autosaved in this browser, and the yellow message shows they aren't in a project yet. Discard changes removes them.

Unsaved patterns stay in this browser. Clearing this browser's data for the site erases them, and also the library if you haven't chosen a library folder. Save your work into a project to keep it.

New samples on the MPC

Sample names come from the saved project, because MIDI doesn't carry them. After loading samples, save the project to the card and enter SD mode. If that project is open here, its pad names update within a few seconds, your unsaved patterns are kept, and the previous copy is kept as a backup.

If you edit the same sequence in both places, your unsaved version here is the one that's kept.

~ beside a padOpens that pad's knob lane under the grid, to draw how a setting moves through the sequence. Click it again, or × in the lane, to close it, and open as many pads as you like. Mode in the lane picks the pad's own filter mode, as the MPC's mode knob sets it, with no drawing: Off, Classic, LPF2, LPF4, HPF2, HPF4, BPF2 or BPF4. It's saved into the project, for every sequence. Drag to draw, Alt-drag to erase, and Clear removes that setting's movements for the pad. A setting holds its value until the next point, as on the MPC. The ~ is coloured on pads that have movements, including ones recorded on the MPC, and * in the menu marks which settings. They're saved into the project with Save or Copy to card, and the MPC plays them from there: it can't follow them over MIDI, so you won't hear them from this page. Undo takes back a stroke, and Shift moves them with the notes.
RecRecords notes into this sequence from the input and channel beside it: the MPC's pads, another keyboard, or any input. While playing, hits land exactly where you play them, or on the nearest step with Snap to steps chosen beside Rec, and last as long as they're held, or the New note length if it isn't Off, and each time round the loop adds more, then play back on the MPC like any other steps. While stopped, each hit adds a note and moves on a step. Undo takes back the whole take. Notes from another keyboard are passed on to the MPC while recording, so you hear them.

Buttons and settings

ProjectChoose a project. "No project" gives you blank pads for live playing, but those patterns can't be saved into a project.
Connect cardChoose the card folder. The badge beside it shows whether the card is available.
Sequence 1-16Switch patterns, or click an empty slot to start one. Drag a pattern onto an empty slot to move it there. Duplicate copies it instead. During playback, the new slot starts when the current loop ends.
PlayPlay the pattern on the MPC, looping. Don't press play on the MPC as well.
PanicStops playback and silences any notes still sounding on the MPC.
Record into MPCRecords this track's notes into a sequence on the MPC. Clicking it shows the steps to get the MPC ready. Then the page waits, and when you start recording on the MPC, it plays the loop once in time with the MPC's clock. It needs MIDI Sync Out on MIDI Clock on the MPC. This hasn't been confirmed on the hardware yet.
BPMPlayback speed from this page. It isn't saved to the project.
Live volume and Live panMove the whole track's volume or pan on the MPC right away, even while it plays. They affect every pad and aren't saved to the project. Double-click Live pan to centre it. Reload the project on the MPC to undo them.
BarsLength of the current pattern. Shortening it removes notes past the new end, and Undo brings them back.
Steps and TripletsGrid size: 1/8, 1/16 or 1/32. Triplets puts three steps where there were two.
LengthHow long new steps last. Off records notes as long as they're held, and clicked steps last one step. Choose a longer value for loops, so they aren't cut off in Note On mode.
Note repeatNew steps play 2-8 evenly spaced hits, drawn as bars in the step. They're saved as separate notes.
Output and ChannelWhere notes are sent. The MPC is chosen automatically when it's found.
SyncPlays this page together with the other grids, S-1 Grid, Protein Grid, Bass Station Grid and TD-3 Grid, when they're open in the same browser, each with its MIDI connected and Sync ticked. Pressing Play or Stop on any of them starts or stops them all, from the start of their patterns, at the tempo of the page you pressed, and changing the BPM on one changes them all. The badge beside Sync shows which pages are linked. Sync starts off each time the page opens, so tick it to link the page. Song Grid arranges their patterns into a song and plays them through Sync. The Tools menu at the top opens any of them.
Send clockSends MIDI start, stop and clock with playback. Set MIDI Sync In to MIDI Clock on the MPC to follow it.
Undo, Redo, Duplicate, ClearBeside the sequences. Undo an edit, bring it back, copy the pattern to the next empty slot, or remove all of its notes.
☀ / ☾Switches between dark and light colours, for all the grids at once.
Pad banksBanks A-H hold 16 pads each. A dot means the bank has notes in this pattern. "In use" shows pads with samples or notes from any bank.

Reading the grid

  • Brighter steps are louder.
  • The solid bar shows how long a note lasts, and can run across several steps. Drag the note to change it.
  • Bars inside a step show its separate hits, and these can't be dragged.
  • A white dot means the note starts later than the beginning of the step.
  • A dashed outline means less than 100% probability. It works during live playback here, but it hasn't been confirmed on the MPC after saving.
  • Arrows above the grid appear when a long pattern needs paging, so steps stay large enough to click. Pages turn by themselves during playback.

If you hear nothing

  • Check that the MPC isn't in SD mode, and that the MIDI badge is green. Reload the page if the MPC was in SD mode when it opened.
  • Check the three MIDI settings above.
  • Hit the pad on the MPC itself, to confirm it has a sample and the volume is up.
